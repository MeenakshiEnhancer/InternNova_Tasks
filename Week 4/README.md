# Week 4 Assignment – Statistics, Data Visualization & EDA

## 📌 Overview

This repository contains my **Week 4 Assignment** focused on **Statistics, Data Visualization, and Exploratory Data Analysis (EDA)** using Python.

## 📊 Tasks Covered

* **Statistical Analysis:** Mean, Median, Mode, Variance & Standard Deviation
* **Correlation & Probability:** Correlation analysis and basic probability
* **Outlier Detection:** Identification and analysis of potential outliers
* **Matplotlib:** Line, Bar, Pie, Histogram and Scatter plots
* **Seaborn:** Count Plot, Box Plot, Heatmap and Pair Plot
* **EDA:** Data inspection, cleaning, correlation analysis and pattern identification
* **Insights:** Identification of meaningful patterns and trends
* **Business Recommendations:** Data-driven recommendations based on EDA findings

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## 📁 Dataset

An **Employee Attrition dataset**,**Supermarket Sales** was used for the EDA, correlation analysis, insights, and business recommendations.

## 🎯 Key Learning Outcomes

This assignment provided practical experience in:

* Statistical analysis
* Data cleaning and preprocessing
* Data visualization
* Correlation and outlier analysis
* Exploratory Data Analysis
* Deriving insights from data
* Making data-driven business recommendations
